# Triage（分诊）标签

技能们以五个标准 triage 角色来表述。本文件把这些角色映射到本仓库议题跟踪器中实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本 tracker 中的标签 | 含义 |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估该议题 |
| `needs-info`               | `needs-info`         | 等待报告者提供更多信息 |
| `ready-for-agent`          | `ready-for-agent`    | 已完整指定，可供 AFK agent（无人值守代理）处理 |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现 |
| `wontfix`                  | `wontfix`            | 不会采取行动 |

当某个技能提及一个角色时（例如 "apply the AFK-ready triage label"），使用本表中对应的标签字符串。

编辑右侧列，使其匹配你实际使用的词汇。
