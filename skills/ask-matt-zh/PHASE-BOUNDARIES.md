# 阶段边界（Phase boundaries）

**phase**（阶段）是会话内的一块工作：访谈、实现、QA 都是。这个定义故意模糊：当你想*“好，这件事我们做完了”*时，一个阶段就结束了。

**phase boundary**（阶段边界）是两个阶段之间的空隙，也是这个决定唯一该出现的地方。阶段中途没有决定可做：要么继续，要么把剩下的工作拆给子代理。在阶段中途压缩会让代理失去头绪。

## 五个选项（The five options）

| 选项 | 它的作用 |
| ------------ | --------------------------------------------------------------- |
| **Continue**（继续） | 留在会话中。完全不切换上下文。 |
| **`/clear`** | 清空上下文窗口，从零开始。 |
| **`handoff`**（交接） | 写一个可移植的 markdown 文件，用它可以在任何地方开启会话。 |
| **Subagent**（子代理） | 把任务送到它自己的上下文窗口，拿回一份报告。 |
| **`/compact`** | 压缩这份上下文，用摘要开启一个全新的会话。 |

## 决策树（The tree）

在边界处从上到下依次问。第一个**是**胜出。

**1. 你能在这个会话中继续吗？** 有两件事会让答案是“是”：下一个阶段需要把当前阶段作为 **primary source**（一手来源），或者你剩余的 [smart zone](https://www.aihero.dev/ai-coding-dictionary/smart-zone)（智能区间）（约 150k tokens）足够装下下一个阶段。访谈 → 实现是标准的“是”：实现想要的是原原本本的推理，而不是它的摘要。继续不花成本、不丢东西，所以在任何其他选项之前先排除它。

**2. 这份上下文对接下来无关吗？** 这个会话里的一切（探索、决策、死胡同）都是可丢弃的吗？如果是，**`/clear`**。它是棋盘上最便宜的一步：不花时间，交还整个窗口。`/clear` 也不是终点：旧会话仍然可以恢复。

把这个判断错了的代价是单向的。清掉一份*相关*的上下文，你就失去了所构建之物的**为什么**，再读多少遍差异也找不回来。

**3. 你需要交接吗？** `handoff` 用途很窄。只有在以下情形你才需要它：

- 换到**新的 harness**（运行环境）（Claude → Codex），
- 搬到**新目录**或新仓库，
- 把工作发给**同事**，
- 或者在**阶段中途**发现了一个支线任务，想分叉出去而不打乱手头的事。

这个列表就是全部情形。`handoff` 买来的是**可移植性**：一个能带走的文件。如果没什么要带走的，你就不需要它。

**4. 这个任务能离开键盘（AFK）完成吗？** 它的范围足够紧凑、可以让你离开键盘、无需操控地运行吗？那就把它送给**subagent**（子代理），让这个会话保持原样。自动审查是标准情形：代理读差异并报告，它做这件事时不需要你在场。

**5. 否则，`/compact`。** 上下文相关、同一运行环境、同一目录，而且你需要留在环中：决策树就在这里落地，而且经常在这里落地。给它一条指令（`/compact we're going to QA this area`），这样摘要就会保留下一个阶段需要的东西。

`/compact` 是**默认选项，而不是首选**。它位于底部，因为它上面的四个问题要么更便宜、要么更精确。人们从这里开始时，失败模式是一个全新的会话，对某个被摘要压平的决定自信地出错。

## 一手来源与二手来源（Primary and secondary sources）

除 **Continue**（继续）之外的每一步，都会把 **primary source**（一手来源）变成 **secondary source**（二手来源）：原样发生的会话，被它的摘要取代。这笔交易总是同一个形状：

| 来源 | 信息 | 噪音 | 回旋余地 |
| --------------------------------- | ----------- | ----- | ------------ |
| 一手（Continue） | 完整 | 多 | 小 |
| 二手（`/compact`、`handoff`） | 有损 | 少 | 大 |

这就是为什么问题 1 排在最前。只有当留下的成本超过省下的成本时，你才付出有损的代价。

## 这些都是判断（These are judgement calls）

这些问题并不客观：每个都带有品味，同一个边界在两天里可能走向两个方向。价值在于**按顺序**问它们，在边界处问，而不是在工作进行到一半时问。
